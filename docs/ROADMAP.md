# Humpback 路线

每个阶段只有通过验收门槛才进入下一阶段。主网下单和转账都需要所有者另行批准。

## 第一阶段：安全底座（4–6 周）

| 里程碑 | 内容 | 状态 |
| --- | --- | --- |
| 1.0 | 旧代码审查、三个场所的官方文档核查 | 完成 |
| 1.1 | 工程结构、Decimal 模型、能力声明、精度规则、签名服务边界 | 完成（真实签名算法由 CI 用官方测试向量验证） |
| 1.2 | 四账账本、`UNKNOWN_IN_FLIGHT`、资金调度状态机、风控闸门与监督、紧急停止三阶段 | 完成 |
| 1.3 | 幂等、启动恢复、对账、模拟场所故障注入闭环 | 本地完成；测试网传输层待做 |
| 1.4 | 控制面 API、Web 面板、测试报告、第二阶段交接清单 | 未开始 |

**还没做的**

- 三个场所的网络传输层（REST/WebSocket），以及基于测试网的 1,000 次以上下单、撤单、成交循环
- Lighter 官方签名器的接入
- 控制面 API 与 Web 面板
- 签名服务拆成独立进程（目前是同进程内的独立模块，接口已按跨进程设计）

**验收门槛**：测试网完成 1,000 次以上循环且对账零差异；所有故障注入场景通过。

## 第二阶段：数据层（3–4 周）

行情、资金费率、OI、预言机、清算流入库，使用三时间戳存储；缺口检测与补数（迁移旧项目 v10 `streaming` 模块）；交易员持仓跟踪入库。

## 第三阶段：策略（持续）

回测器、特征注册表、试验账本、DSR/PBO 报告。研究方向依次为：休市定价、条件化 carry、趋势底仓、拥挤后回归。

## 第四阶段：辅助模块

ETF 资金流追踪、交易员质量评分、情绪与波动面板、个人交易终端界面。
